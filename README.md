# 青空文庫リーダー

青空文庫の公開対象作品を読むための非公式Webリーダーです。

## 著作権・データ利用

本プロジェクトでは、青空文庫が提供する書誌情報を利用しています。

- 出典: 青空文庫
- 書誌情報: Creative Commons Attribution 4.0 International (CC BY 4.0)
- 青空文庫: https://www.aozora.gr.jp/
- CC BY 4.0: https://creativecommons.org/licenses/by/4.0/

本プロジェクトは青空文庫の公式アプリケーションではありません。
青空文庫による推薦、認可、運営、支持、その他の関与を意味するものではありません。

作品本文は本リポジトリに一括収録せず、アプリから公開データを必要に応じて取得します。
アプリでは青空文庫の書誌データに含まれる作品著作権フラグを利用し、通常の作品一覧・本文取得・AI機能の対象を公開対象作品に限定しています。

作品本文を利用する際は、各作品に適用される利用条件を確認してください。
